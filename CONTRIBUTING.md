# Contributing to Awesome Data Center Technician

We welcome contributions from hyperscale infrastructure technicians, hardware engineers, and systems operators!

## How to Contribute
1. **Submit Real-World Incident Scenarios:** Anonymize all company-confidential data (no internal hostnames, IP addresses, or proprietary rack designs).
2. **Add CLI Diagnostic Snippets:** Provide reproducible Linux, IPMI, or Redfish commands for hardware triage.
3. **Report Issues or Corrections:** Submit a Pull Request or open an issue.

## Guidelines
* Content must adhere to public industry standards (ANSI/TIA-598-D, IEC 61300-3-35, NFPA 70E, OSHA 1910).
* Do NOT include proprietary non-disclosure (NDA) data from any employer or cloud provider.
